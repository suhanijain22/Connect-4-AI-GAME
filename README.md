# Connect-4-AI-GAME
A browser-based Connect 4 game where players compete against an AI opponent on a 6×7 board. The AI can identify winning moves, block the player, and prioritize the center column. Built using Python, Flask, HTML, CSS, and JavaScript.
# Connect 4 AI

A browser-based Connect 4 game where players compete against an AI opponent on a 6×7 board.

## Features

- Player vs AI gameplay
- Win detection
- AI move selection
- Interactive game interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Install Flask:
   pip install flask

2. Run the application:
   python app.py

3. Open the provided localhost link in your browser.
